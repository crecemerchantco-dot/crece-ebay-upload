# Crece Merchant Co eBay Photo Uploader — starter

This is a private single-seller **photo uploader**, not an automated listing publisher. It accepts images from your phone, uploads them directly to eBay's Media API and shows the returned eBay-hosted URLs in order. It does **not** create a CSV yet or update Google Sheets.

## Deploy and complete the eBay form

1. Create a **private** GitHub repository and upload `app.py`, `requirements.txt`, `render.yaml` (do not upload credentials). Connect the repository in Render via **New > Blueprint** and select `render.yaml` (or create a Python web service with the listed build/start commands).
2. Set the environment variables in Render: `EBAY_CLIENT_ID`, `EBAY_CLIENT_SECRET`, `FLASK_SECRET_KEY` (random 32+ bytes, generated by Render), and `PUBLIC_BASE_URL`. Use the real HTTPS URL Render gives you, such as `https://YOUR-ACTUAL-SERVICE.onrender.com` — **do not literally use this example**.
3. In eBay Developer Portal > Production > User Tokens > Add eBay Redirect URL: Display Title `Crece Merchant Co eBay`; privacy policy URL `https://YOUR-ACTUAL-SERVICE.onrender.com/privacy`; auth accepted URL `https://YOUR-ACTUAL-SERVICE.onrender.com/oauth/callback`; auth declined URL `https://YOUR-ACTUAL-SERVICE.onrender.com/oauth/declined`. Save the form, then copy the **generated RuName** into Render's `EBAY_RUNAME` variable. eBay may allow its default declined URL, but a real declined endpoint is included here.
4. Open your Render URL, select **Connect your eBay seller account**, sign in to eBay and approve the `sell.inventory` permission. Do not paste the authorization code, tokens or Client Secret into chat.
5. Select up to 24 images on the uploader page, with your desired gallery image first. It returns EPS URLs in order. Save those URLs for your eBay Seller Hub CSV. No listing is published by this app.

## Security and limits

- Single-seller prototype. The landing page is publicly reachable and does not have its own login; OAuth protects the upload function, but for long-term use add a separate app login, CSRF protection for forms, rate limits and request-size limits per image.
- OAuth tokens are stored **only in process memory**, not cookies or databases; app restarts require reconnecting eBay. `FLASK_SECRET_KEY` must be set and kept secret. Use a single Gunicorn worker as configured.
- Render may sleep or restart the free service. Images are streamed through the server and are not saved to disk. eBay image URLs may expire if unused; list promptly.
- A privacy exemption is appropriate only if your actual deployed application meets eBay's criteria. Hosting-provider logs may still contain ordinary metadata. Review before submitting compliance statements.
- For a reliable production uploader, add persistent encrypted token storage and reassess eBay deletion compliance as appropriate; add tests and failure retry.
